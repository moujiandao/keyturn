Keep the stack

The existing modules and route structure provide useful seams. A rewrite increases migration risk while leaving authorization and workflow mistakes to be solved again.

Tradeoff: incremental migration temporarily supports old and new paths. Move a complete feature slice and remove the old path.

Start delivery in the existing database

Extend the current message tables and scheduler before adding a queue vendor. Introduce a separate queue only when workload and operations justify it.

Tradeoff: the application owns claim expiry, retries, and reconciliation.
